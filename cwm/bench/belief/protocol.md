# Frozen first-write protocol

Question: can history distinguish sharing from equal array contents, and can learned write and sharing effects be recombined? This is a **breakpoint-conditioned array-state forecast**, not raw-pause or full-rollout prediction. Site and binding roles are supplied alignment, not learned. Keep the raw-frame predictor/readout scores separate.

- Four setup forms × four write forms, both flag values × both indices. Split whole source compositions by checkerboard; every setup and write appears on both sides. Training cannot inspect test labels. No fit or model selection on test. Do not count the 32 dependent test examples as independent families.
- Commit the fixture before scoring. Project real V8 traces, verifying the same source/site/state for both pre-write twins after erasing visible history and distinct array-state successors. No runtime handles, entry arguments, future state, outcome, split, program or trace ID in forecast inputs. Context is static setup and write, earlier observed flag, current index and arrays. Retain actual traces for replay.
- Primary endpoint: predict both post-write arrays exactly on all four trials in at least seven of eight unseen compositions. Count ties and abstentions as misses. A stronger baseline winning the same cells is a result, not a reason to tune the architecture. The constant terminal result is uninformative.
- Remove history: distinguish a calibrated mixture from a confident wrong answer. Balanced indistinguishable twins imply a deterministic current-only ceiling of 1/2 and optimal multiclass Brier of 1/2 (sum, not mean, over states). Score Brier and natural-log loss on the entire test set. An empty forecast places all mass on an extra abstention outcome; any impossible observed outcome makes log loss infinite. Report coverage and wrong decisions.
- Compare source-pair lookup, persistence, a joint learned two-layer softmax delta classifier and a factored sparse effect/belief model. Fit on identical labels. Compare full and masked history. For the neural control fix hidden width 32, three seeds (1, 2, 3), 600 full-batch updates, learning rate 0.15 and no hyperparameter search. A held-out pair is not a novel primitive. Test fitting without labels, and flipping the historical signal only in the training set.
- Interchange the historical signal between balanced twins at inference: a correct prediction must change only the potentially shared array, preserving the directly written array. This tests sensitivity to the input, not internal discovery of a human-interpretable alias variable. Report per-cell results, not only a pooled average.
- The parallel straight-line benchmark tests a **different** claim: whether functions learned from primitive observations compose at unseen structural depths. Neither benchmark demonstrates general TypeScript interpretation. Do not replace the production predictor on this evidence.

**Label-efficiency intervention, specified before scoring.** Form a bipartite graph from training inputs alone: (setup, signal) on the left, (write, index) on the right, each candidate observation an edge. Select a minimum edge cover without reading its successors. Compare the factor model fit on only those labels with uniform subsets without replacement of identical size, seeds 1–20. Retrospective label efficiency, not a measurement of oracle time saved: the input contexts are already observed. A cover guarantees appearance, not that the outcome identifies the effect.
