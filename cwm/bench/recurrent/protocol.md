# Predict complete V8 observations across loop backedges

Freeze the source families, layouts and inputs in `cases.ts` before collecting held labels. Compare two equal-cost curricula. Both observe the same eight training bodies on the same six inputs. One repeats layouts. The other changes names, indentation and return spacing for half the inputs. All children of a held body stay held. The two layouts and four inputs per test family are repeated measures. They are not independent source families.

Fit scalar effects and comparisons from adjacent observed stores and branch successors. Supply lexical binding, assignment destination, a static CFG including backedges, and a hypothesis class over AST-relative source positions. Learn which event kind and position a visit emits and condition on incoming syntax where an assignment can elide a return-statement pause. Use neither held-out breakpoint lists nor a debuggee in prediction. Freeze the predictor before held collection. A matched ablation fits statement-relative character offsets; another corrupts learned scalar semantics. Score the existing WorldModel and entry return readout on identical targets.

Count full next-observation exact, wrong and abstain, separately for module, function nonterminal and terminal transitions. Credit a rollout only from its first observed function frame until the first miss or abstention, through its terminal result. Report survival by horizon, by family and layout, both twins jointly, and sensitivity to training layout at the same run budget. The twins return the same value with opposite intermediate updates. Include the untrained XOR family in all aggregate scores. Test whether identical visible module prefixes have incompatible successors when invocation arguments are unavailable. Report oracle or projection failures explicitly.
