# Independent localized-edit evaluation

Three new multi-file TypeScript libraries each have two original requests. Their selected implementation path, initial files, requests, visible and hidden checks, and reference edits are sealed together before access to candidate weights. The trainer receives only the seal until weights are fixed. The original project benchmarks keep their existing scores.

On the frozen gold trajectory, add the current visible test to earlier visible tests. Run that snapshot and each hidden test independently with the pinned Bun Docker runner. The gold predecessor must fail the new visible and hidden behavior, pass any earlier hidden suite, and parse with Oxc. Apply the exact reference line splice. Its successor must parse and pass the cumulative visible and hidden suites. Retain actual preflight output. The first predecessor is the initial source. At turn two it is the actual reference successor of turn one.

Start each checkpoint from the original project separately. Supply only the current goal, selected path, sorted current visible files and compact actual pre-edit test observation in one NDJSON request to the specified Python editor. Start with no hidden tests in the workspace, add visible tests cumulatively, and carry accepted edits into the follow-up even after test failure. Use exactly one model request per turn. Base and trained get the same host, budgets and feedback rules. Keep the exact request and raw response, duration, reported bounds and replacement. The editor chooses the location and payload. Check integer zero-based half-open line bounds, exact byte reconstruction of the reported text and a clean Oxc parse. Split LF lines retaining terminators and the final unterminated line. An empty source has zero lines. Rejected replies leave the working copy unchanged. Score every resulting snapshot, including rejections, in fresh containers. A solved turn requires an accepted changed edit and passing visible and all hidden suites through that turn. Record hidden-only results separately.

After inference, where the actual predecessor is byte-identical to the frozen reference predecessor and the response supplies a usable in-bounds interval and payload, apply two counterfactuals on independent copies. One injects the reference replacement at the model interval. The other injects the model replacement at the reference interval. Reparse each hybrid and grade all visible and cumulative hidden tests for parsable candidates. Report exact location and replacement agreement separately from behavioral success. Do not invent spans for abstentions or transplant a reference interval into a divergent predecessor. No hybrid, hidden result or reference enters the model request, its history, or the policy score.

Retain raw Bun observations, eligibility reasons, exact spans, code and grades for both hybrid snapshots. A machine-readable row for every arm, project and turn links to its full transcript and includes its goal, pre-edit observation, source digest, outcome, location and replacement diagnostics and elapsed query time. Record editor revision, resolved artifact hashes and model snapshot identity with the run. The three project lineages define this evaluation's scope.
