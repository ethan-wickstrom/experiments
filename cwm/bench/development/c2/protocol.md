# Frozen C2 training protocol

Build from release MiniCPM5-1B ac83f813ba7da263c51a9f3ec37c2072597e54af, independently of all evaluation projects and scores. Use the same verified release loader as A/B/C. One rank-32, alpha-32 adapter on the last MLP down projection uses 196,608 trainable coefficients. Optimize 512 AdamW updates, seed 17, learning rate 0.001, with 64 supervised positions per update. Draw 36 raw file positions, 8 decision positions, 6 passing write-label positions, 6 failing write-label positions, 2 rejection-label positions, and 6 native execution positions. Sample forecast positions from word tokens only, so an easy assistant stop cannot dominate outcome learning. All raw files, decisions and V8 pauses supervise the assistant stop as well as the text. The target raw file includes its final newline.

Each of ten training projects has three successive goals and a counterfactual alternate user requirement at every turn. The two requirements have identical starting source and candidate source bytes. A plausible candidate passes one requirement and fails the other under real Bun tests. Only the first fork continues to the next goal. Later requests see the actual accepted source. The stock chat generation prefix ends with the empty thinking block. Append the response tokens to that exact inference prefix for teacher forcing. Audit source round-trips and all prompts and targets for embedded release control tokens. Apply the shared reversible JSON escaping before stock template rendering. Inference preserves generated whitespace up to an actual release EOS. Capped outputs are marked incomplete.

Use the frozen wire for directed source generation and a separate four-word decision. A host chooses the file. Parent live fixtures, source branches and evaluation outcomes are inaccessible to the experiment. Report direct unconstrained generation, decision accuracy, candidate-pair ranking and native next-pause retention separately. Use isolated tests for any generated code, with no repository or host credential access. Do not select a checkpoint by probe results. Keep the released A/B/C artifacts unchanged.
