# Frozen A/B/C protocol

A is the MiniCPM5-1B post-trained release at ac83f813ba7da263c51a9f3ec37c2072597e54af. B and C each initialize a new rank-16, alpha-16 LoRA on the final MLP down projection (98,304 FP32 parameters). Train 256 updates of 48 target positions with AdamW at 0.001 and seed 17. B receives policy positions only. Each C update draws 24 policy, 12 execution, and 12 test-consequence positions. Uniform sampling within each task is over target positions including the assistant stop. Both derivatives share a frozen feature cache. No held coding projects, model tuning, previous LoRA weights or held outcomes enter fitting.

Six training libraries each supply one initial request and one successive request. The user supplies the expanded test file with the second request. A demonstrated write is retained after actual Bun verification. Read and test observations are separate history events. A counterfactual restores the same file after each candidate and runs the same checks. Test forecasts predict an actual test outcome. Write forecasts predict the downstream test outcome when accepted, and unread replacement is rejected. The learner sees only the sorted filenames and observed prefix before acting or forecasting. A candidate is visible only for its forecast. The next-pause task uses the existing immutable fixed tape with 98 pairs and the original prompt.

Freeze both adapters before observing the fresh retention labels or accessing held development tasks. Retention uses three new scalar programs with two calls each. Score all gold-prefix next pauses, event and site, locals, changed locals and completely exact uninterrupted rollouts from function entry. The rollout horizon is conditional on another pause existing. A mismatch ends exact-prefix survival. The separate live development evaluation belongs to the runtime owner.
