# Decisions

**Learn branch choice separately from debugger landing position.** Static CFG edges provide possible transitions, not the arm taken. The [observed arm experiments](bench/branch/README.md) support semantic paths but expose large raw-site errors. Keep both targets. Use [class-identifying probes](bench/composition/fingerprint.md) only with independent falsification; a unique fit alone even gives spurious polynomials for bitwise operators.

**Research track: factor sparse effects, not whole snapshots.** The [architecture and promotion gate](RESEARCH.md) separates locating the next event, learning a state change, and maintaining a distribution when observations cannot distinguish possible successors. We rejected replacing the public predictor on the strength of a different target. The [scalar falsification](bench/composition/regime.md) shows why within-class agreement needs distinguishing interventions; the [alias study](bench/belief/README.md) shows why hiding an informative prefix must change confidence. Selecting covering contexts reduced labels in replay, not the cost of a completed oracle run.

1. **Observe a real engine rather than inject hooks.** The debugger sees scopes and control transfers without rewriting returns, duplicating predicate evaluations, or reading a binding before initialization. A fresh debuggee per run costs startup time but eliminates shared collector state. Bun owns orchestration; V8 supplies break locations, return values and scope descriptors.
2. **Compile modules separately.** Oxc's source maps preserve original positions. The native ESM linker handles cycles, re-exports and live bindings. A bundled executable or a hand-sorted CommonJS dependency graph would hide module boundaries. The resolver has only one job: match explicit relative imports to the provided in-memory files.
3. **Learn a measurable baseline.** Use state-conditioned retrieval and identifiable affine transitions before introducing neural training infrastructure. Score held-out observations and allow abstention. These results say nothing about a large pretrained model's accuracy.
4. **Store evidence once.** Structured JSONL replaces delimiter parsing, masked duplicate frames and inferred trace modes. The actual source, locations and checked shape are sufficient to form supervised pairs. No old record formats, migration paths, guessed failures, or action-bigram deduplication.
5. **Invert edits, not guesses about intent.** An edit contains its original slice and offset. Restore those exact characters and run the repository again. Retain unsuccessful interactions rather than generating a synthetic diagnosis or treating any return as a pass.
6. **Use Effect Schema for JSONL boundaries.** Use the published Effect v4 package matching the local reference rather than maintaining a second validation library. Reject excess properties at every level and derive mutable TypeScript types from the schemas so the wire format and public types stay compatible.
7. **A failed observation must not depend on the guest yielding.** On collector failure the observer writes the diagnostic directly to the debuggee's stderr descriptor and signals its own disposable process. Worker-port messages and [worker stdio](https://nodejs.org/api/worker_threads.html#synchronous-blocking-of-stdio) require the main event loop. Keep the independent wall deadline for programs with no further observable stops.
8. **Predict only where the evidence distinguishes an answer.** Refines decision 3: prefer consensus of equally close examples to an input-order tie-break. Fit on independent rows and columns, cross-check against the other observations and check dependent coordinates before extrapolating. This is the [estimable prediction](https://search.r-project.org/R/refmans/stats/html/predict.lm.html) distinction, not permission to use an arbitrary minimum-norm solution off the training subspace. Use the existing matrix package; do not round outputs or add a new solver.
9. **Scale the labels before the model.** Keep a fresh debuggee per run. Independent, atomically published JSONL records allow interrupted collection to resume without a service, persistent worker or cloud account. Compare source transfer against filename removal and copying an observed return, not solely against a source-keyed model that cannot answer. [The experiment](bench/README.md) did not justify promoting either syntax representation.
10. **Distinguish the site, the write, and the return.** In the [paired histogram witness](bench/first-write/README.md), opposite writes lead to the same next site and final value. Neither is a substitute for a correct intermediate array, and a teacher-forced observation cannot restart a failed rollout for credit.
11. **Project before the protocol formats values.** Refines decision 1: Node 24's [V8 error formatter](https://github.com/nodejs/node/blob/v24.19.0/deps/v8/src/inspector/value-mirror.cc) performs property reads. Marking its finished description inexact, disabling previews, or checking only the terminal result is too late. A private helper reads descriptors inside the debuggee using host intrinsics; only detached JSON crosses the protocol. Reject a pause that already directly exposes a native Error. [Differential regressions](cwm.test.ts) compare against an ordinary Node process.
12. **Keep action conditioning experimental.** [Binding-aware statement keys](bench/actions.md) distinguish the controlled operators, literals and operand order. They do not solve unseen compositions; keep the production predictor and prior baselines unchanged.
13. **Condition entry on the host invocation.** Identical module prefixes in the [raw-frame study](bench/recurrent/README.md) lead to four different observed parameter stores. Expose a separate call action or begin at an observed entry for the two deployment interfaces.
14. **Fit the observation cadence jointly with its landing.** Parameter bindings and static CFG edges supply candidate transitions. Learn scalar rules, predicates and event/anchor hypotheses from observed examples. AST-relative coordinates transferred across layouts. Adding compiler-mapped return anchors tied the simpler model. The feature for reachable predecessors transferred after training on join contexts at equal invocation budget. Keep the predictor experimental while independent multi-function and heap evidence is absent.
15. **Seal the complete benchmark tape.** An omitted training iteration or a replay beginning at the last return can retain valid metadata. Hash all normalized frames, sources, arguments and outcomes, and check against an independently recollected reference. Keep verification outside the prediction interface so a function can abstain on unsupported syntax and still count in the evaluation.
16. **Make predictions part of the edit loop.** The [prompt interface](PROMPTING.md) gives the structured model only source and invocation. Compare forecasts against explicit return and ordered-local constraints outside that model. A unique satisfying single edit can change the draft; a fresh oracle run can falsify that prediction. Prompting a language model for both an edit and a verdict would remove the independent behavioral signal.
17. **Train and expose the neural transition model directly.** Use the same trace-adapted MiniCPM5 checkpoint for natural-language revision and conditional next-pause generation. Keep the structured learner responsible for call rollouts while the [held-out neural experiment](bench/minicpm/README.md) lacks evidence of learned writes. A shared chat format alone supplies no execution supervision.
