            How this was made

            This map is generated in your browser from a fixed recipe, the same on every visit, so no one’s files are in it. Folder names follow the tools that make them: git worktrees a coding agent keeps inside a project, Cargo’s target folder, Xcode’s DerivedData and simulator devices, Docker Desktop’s disk image, Playwright’s browsers, and the Hugging Face cache. Sizes are typical of what developers report, not measured on one Mac.

            See your own Mac this way

            Sizewise scans any folder or disk on your Mac and draws every file in it, with the same map, search and zoom.

            Scanning is free, with no account. A license, $12.99 once, adds Move to Trash, Show Changes and Compare with Saved Scan.
