# Rachis

A typeface family for dense technical reading, generated by a program.

- **Rachis Mono**: fixed pitch, for code, terminals and plain-text mathematics. 2113 glyphs.
- **Rachis**: proportional, for prose with notation in it (textbooks, technical writing, mathematics), with an optical-size axis for small print. 1533 glyphs.
- **Rachis Math**: the Regular of Rachis with an OpenType `MATH` table, for typesetting formulas with Typst, LuaLaTeX or MathML. 3354 glyphs.

All are drawn by the same glyph programs: one letter is one function, and weight, optical size, slant and pitch are its parameters. Rachis Math adds nothing drawn by hand: a variable is the italic's letter, a tall parenthesis is the parenthesis's program run with taller brackets, and an arrow or a brace of any length is assembled from pieces cut out of the sign's own outline. The families are designed as small print (x-height 0.54 em, sturdy low-contrast strokes, open counters) and their confusable characters differ in outline: `0 O`, `1 l I |`, `5 S`, `8 B`, `rn m`, `v ν ∨`, `x χ ×`, `∑ Σ`, `⟨ <`. There are no ligatures: what is on the screen is what is in the file.

## The fonts

`fonts/` holds the build's output:

| | |
|---|---|
| `variable/RachisMono[wght].ttf`, `RachisMono-Italic[wght].ttf` | weight 300 to 700 |
| `variable/Rachis[opsz,wght].ttf`, `Rachis-Italic[opsz,wght].ttf` | optical size 8 to 16, weight 300 to 700 |
| `ttf/RachisMono-*.ttf`, `Rachis-*.ttf`, `RachisSmall-*.ttf` | static fonts: Light, Regular, Medium, SemiBold, Bold, each with its italic; overlaps removed; hinted |
| `ttf/RachisMath-Regular.ttf` | the mathematics font: one static style, because a `MATH` table cannot vary |
| `webfonts/*.woff2` | the four variable fonts and Rachis Math for the web |
| `SHA256SUMS` | the build is reproducible: `sha256sum -c SHA256SUMS` |

Install the variable fonts, or the static ones where software does not take variable fonts. Rachis Small is the small optical size of Rachis as a static family, for captions, footnotes and the scripts of formulas where there is no optical-size axis.

For the web:

```css
@font-face { font-family: "Rachis"; src: url("Rachis[opsz,wght].woff2") format("woff2"); font-weight: 300 700; }
@font-face { font-family: "Rachis"; src: url("Rachis-Italic[opsz,wght].woff2") format("woff2"); font-weight: 300 700; font-style: italic; }
@font-face { font-family: "Rachis Mono"; src: url("RachisMono[wght].woff2") format("woff2"); font-weight: 300 700; }
```

A browser sets the optical size from the font size by itself.

Formulas, with Rachis for the text around them:

```typst
#set text(font: "Rachis")
#show math.equation: set text(font: "Rachis Math")
```

```latex
\usepackage{unicode-math}   % LuaLaTeX
\setmainfont{Rachis}
\setmathfont{RachisMath-Regular.ttf}
```

```css
@font-face { font-family: "Rachis Math"; src: url("RachisMath-Regular.woff2") format("woff2"); }
math { font-family: "Rachis Math", math; }
```

Rachis Math has the letters of a formula in italic, bold, bold italic, sans-serif and monospaced, forms of their own for scripts, fourteen sizes of each delimiter up to 6 em, pieces for taller parentheses, brackets, braces, bars, floors and ceilings, a radical in twelve sizes, display sizes of sums and integrals, wide accents, and arrows and braces that stretch to any length. It has one weight, and no script or Fraktur alphabet yet; a typesetter takes those from another font (`docs/ledger.md`, G19 to G21).

Features: `zero` (slashed zero; the fixed pitch has it by default), `ss01` (dotted zero), `ss02` (plain zero), `sups`, `subs`, `sinf` (superior and inferior figures and letters), kerning in Rachis, mark positioning in both. Rachis Math adds `ssty` (the forms for scripts) and `dtls` (dotless `i` and `j` under an accent), which a formula typesetter applies itself.

The fonts are licensed under the SIL Open Font License 1.1 (`OFL.txt`); the source under the repository's Apache-2.0 licence.

## Building

Rust 1.90 or later; ttfautohint on the path if the static fonts are to be hinted.

```sh
cargo run --release -p rachis -- build          # fonts/: 40 files in about twenty seconds
cargo run --release -p rachis -- check          # the masters of every glyph have one structure
cargo run --release -p rachis -- measure --check   # no confusable pair is nearer than recorded
cargo run --release -p rachis -- math           # what Rachis Math holds; --refs DIR compares it with other mathematics fonts
cargo run --release -p rachis -- specimen -o specimen.html   # the specimen page, fonts inside
cargo test
```

`docs/drawing.md` shows how a glyph is written and proofed, and how the formula sheets in `proofs/` are set with Typst, LuaLaTeX and a browser.

## Layout

- `crates/kernel`: plane geometry, Hobby's spline, superellipse corners, pens and stroke expansion, the canvas and the registry of glyph programs, the masters' parameters.
- `crates/glyphs`: the glyph programs, one module per group (`lower`, `upper`, `digits`, `punct`, `operators`, `math`, `arrows`, `greek`, `latin`, `letterlike`, `scripts`, `symbols`, `shapes`, `technical`, `typography`, `boxes`), the proportional family's widths (`text` for letters, `signs` for signs), the computed kerning (`kern`), what the mathematics font adds (`mathfont`) and the cutter that finds the pieces of a sign that stretches (`cut`).
- `crates/font`: the compiler from masters to OpenType: variation model, quadratic conversion, `glyf` and `gvar`, layout tables, the `MATH` table, static instances with overlaps removed, WOFF2.
- `crates/cli`: the `rachis` command: `build`, `check`, `proof`, `measure`, `math`, `digest`, `specimen`, `widths`, `kern`, `list`.
- `proofs/`: sheets of formulas for Typst, LuaLaTeX and MathML, each with the command that sets it.
- `specimen/`: the source of the specimen page, a single HTML file that `rachis specimen` fills with the web fonts.
- `docs/`: `design.md` (the brief and the forms), `decisions.md` (each decision and what it rejected), `drawing.md` (the method), `measurements.md` (generated), `ledger.md` (what is open), `research/` (the reports the decisions cite).
