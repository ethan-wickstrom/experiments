# Rachis

A monospaced typeface for code, plain-text mathematics and terminal interfaces. It was made for one reader, the owner of this repository, and it is generated by the program in `src/rachis`: every glyph is a function, and weight and slant are parameters.

A rachis is the axis of a frond, the stem its leaflets hang from at regular intervals.

## The fonts

`fonts/` holds the build:

| Directory | Contents |
|---|---|
| `variable/` | `Rachis[wght].ttf` and `Rachis-Italic[wght].ttf`: weight 300 to 700 |
| `ttf/` | static TrueType fonts, hinted: Light, Regular, Medium, SemiBold, Bold, and their italics |
| `otf/` | the same as OpenType/CFF |
| `webfonts/` | WOFF2 of the variable and static TrueType fonts |
| `SHA256SUMS` | the SHA-256 of every file above; `sha256sum -c SHA256SUMS` checks them |

Install the variable fonts if the terminal or editor can select a weight on an axis, and the static `ttf/` files otherwise. The fonts are licensed under the SIL Open Font License 1.1 (`OFL.txt`).

## What it does

- One character, one glyph, one cell. No ligatures and nothing contextual: the screen shows what the file holds.
- Confusable characters differ in outline: `0 O`, `1 l I |`, `5 S`, `8 B`, `g q 9`. The differences are measured against other code typefaces (`docs/measurements.md`).
- Operators share one axis, one stroke and one span, so `->`, `=>`, `<=` and `|>` line up; mathematical signs are built from the same parts and sit on the same axis.
- Box drawing, block elements and braille fill the cell exactly and connect across cells and lines.
- It covers every character this repository uses, apart from emoji and CJK; a test keeps that true.

Features, all optional: `ss01` dotted zero, `ss02` plain zero, `sups` and `subs` for superior and inferior figures.

## Building

```sh
uv sync
uv run rachis build          # writes fonts/
uv run rachis proof --text "hamburgefonstiv" -o /tmp/proof.png
uv run rachis check          # every glyph, every master
```

The build is reproducible: the same source gives the same bytes, and `fonts/SHA256SUMS` records them.

Checks, from this directory:

```sh
uv run python -m unittest discover -s tests -t .
uv run ruff check
uv run ruff format --check
uv run ty check
```
