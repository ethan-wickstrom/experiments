# Rachis

The repository's rules are in `../CLAUDE.md`; this file adds what is specific to Rachis.

## Purpose

Rachis is a typeface family made for the owner of this repository, a software engineer and mathematics student, for effortless reading of dense technical text at small sizes: Rachis Mono (fixed pitch: code, terminals, plain-text mathematics) and Rachis (proportional, with an optical-size axis: textbooks, technical writing, mathematics). It is generated by a program. Every glyph is a function over a small kernel (pens on skeletons, Hobby splines, superellipse corners); weight, optical size, slant and pitch are parameters; and the fonts in `fonts/` are a build product that the source reproduces byte for byte. Push the frontier of what a programmed typeface can be, and measure every claim made for it.

The owner asked for the generator to be written in lower-level languages, so it is Rust.

## Resuming

1. `docs/ledger.md` says what is open; `docs/decisions.md` (T-numbers) says what was decided and what each decision rejected; `docs/design.md` is the brief and the forms; `docs/drawing.md` is how a glyph is written and judged; `docs/measurements.md` is generated by `rachis measure`; `docs/research/` holds the reports the decisions cite.
2. The specimen page is `specimen/specimen.html`; `rachis specimen -o FILE` fills it with the web fonts, and the result is published as an Artifact (ledger G13 says what in it is copied by hand).
3. Layout: `crates/kernel` (geometry, pens, the canvas `Draw`, the registry, `params.rs` with the masters and the four faces), `crates/glyphs` (the glyph programs by module, `text.rs` for the proportional widths, `kern.rs` for the computed kerning), `crates/font` (the compiler), `crates/cli` (the `rachis` command).
4. Nothing is in flight. The next work is the ledger's gaps in the order G1, G4, G2.

## Rules

- A glyph program never branches on weight, optical size or slant: the masters of a variable font must have the same structure. It may branch on `p.mono`, because the two families are different fonts. `rachis check` compares the masters.
- Shapes are judged by eye on proofs, at every master, large and at 13 to 16 px, beside the characters they could be mistaken for (`docs/drawing.md`).
- A number quoted in a document comes from a command that can be rerun.
- After a change to shapes: `rachis digest --write`, `rachis build`, and commit `tests/snapshot/outlines.sha256` and `fonts/` with it. Regenerate `docs/measurements.md` when a shape that it measures changes.
- Checks, from `rachis/`:
  - `cargo test`
  - `cargo clippy --all-targets`
  - `cargo fmt --check`
  - `cargo run -q --release -p rachis -- check`
  - `cargo run -q --release -p rachis -- build --out /tmp/rachis-check && diff fonts/SHA256SUMS /tmp/rachis-check/SHA256SUMS` (the committed fonts are the source's)
