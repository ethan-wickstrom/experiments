# Rachis

The repository's rules are in `../CLAUDE.md`; this file adds what is specific to Rachis.

## Purpose

Rachis is a monospaced typeface for code, plain-text mathematics and terminal interfaces, made for the owner of this repository: a software engineer and mathematics student who reads code, logs, hashes and Markdown in terminals all day. It is generated by a program. Every glyph is a function over a small kernel (pens on skeletons, Hobby splines), weight and slant are parameters, and the fonts in `fonts/` are a build product that the source reproduces byte for byte. Push the frontier of what a programmed typeface can be, and measure every claim made for it.

The owner asked for the generator to be written in lower-level languages, so the implementation is Rust. Python is used only where the standard tool of the trade is Python (fontbakery for quality checks).

## Layout

- `crates/kernel`: plane geometry on complex numbers, Hobby's spline, pens and stroke expansion, the canvas (`Draw`) and the registry of glyph programs, structural checks.
- `crates/glyphs`: the glyph programs, one module per group, and the skeleton parts they share (`parts.rs`).
- `crates/font`: the compiler from masters to OpenType files (variation model, quadratic conversion, tables).
- `crates/cli`: the `rachis` command.
- `prototype/`: the Python prototype the Rust was ported from. `tools/oracle_dump.py` and `tools/oracle_diff.py` compare every outline of every master between the two. It stays until the Rust has replaced it everywhere, and is then deleted.
- `docs/design.md`: the brief, the principles and the forms. `docs/decisions.md`: each decision (T-numbers) with what it rejected. `docs/drawing.md`: how a glyph is written and judged. `docs/ledger.md`: what is open. `docs/research/`: the research reports the decisions cite.

## Rules

- A glyph program never branches on weight: the masters of the variable font must have the same structure. `rachis check` compares them.
- Shapes are judged by eye on proofs, at every master, large and at 13 to 16 px, beside the characters they could be mistaken for (`docs/drawing.md`).
- A number quoted in a document comes from a measurement that can be rerun.
- Checks, from `rachis/`:
  - `cargo test`
  - `cargo clippy --all-targets`
  - `cargo fmt --check`
  - `cargo run -q -p rachis -- check`
